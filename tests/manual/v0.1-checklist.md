# CTRM v0.1 manual checklist

Do these checks before each release, on macOS, Windows 11 and Linux (KDE and GNOME), unless a
line names one system. Write the result (Pass, Fail and the issue number, or N/A) and your
initials in the last column.

| ID | Check | Procedure | Expected result | Result |
|---|---|---|---|---|
| AC-G2 | No network connection | Start a network monitor (Little Snitch on macOS, Resource Monitor on Windows, `ss -tp` on Linux). Add items, edit rules, rename, undo, open History. | The monitor shows no connection from CTRM. | |
| AC13.5 | Journal is readable | After a batch, open its `.jsonl` file from the history folder in a text editor. | Each line is one JSON object. The names and the steps are easy to read. | |
| AC13.9 | Weak identity on exFAT | Rename 10 files on an exFAT USB stick. Do Quick Undo, then open the undo preview from History. | Quick Undo opens the undo preview. The preview shows "Weak identity check". Undo restores all names. | |
| SMB | Network share | Rename 10 files on an SMB share. Undo the batch. | The rename and the undo complete. No `.ctrm-tmp-*` name stays. | |
| AC12.4 | Case-sensitive APFS (macOS) | On a case-sensitive APFS volume, rename `photo.JPG` to `photo.jpg`. Then rename `A.txt` and `a.txt` in one folder to new names. | Both batches complete. No conflict between `A.txt` and `a.txt`. | |
| Style | Native styles | Open the main window, the folder question, Preferences and History on macOS, Windows 11, KDE and GNOME. | The controls use the platform style. No text is cut off. | |
| Theme | Light and dark mode | Change the OS between light mode and dark mode while CTRM runs. | All text, tints and icons stay easy to read in both modes. | |
| Contrast | High-contrast mode | Turn on the OS high-contrast mode. | All text and the status tints are visible. The focus frame is visible. | |
| Scale | 200% text scale | Set the OS text scale to 200%. | The forms keep one field edge. No text is cut off. | |
| Reader | Screen readers | Use VoiceOver (macOS), Narrator (Windows) and Orca (Linux) on the flow strip and on one table row. | The reader speaks the step names and the row old name, new name and status. | |
| AC-G3 | Keyboard only | With no mouse: add files, add an Insert rule, type its text, rename, undo, open History. | All steps are possible with the keyboard. The focus is always visible. | |
| AC12.8 | Kill during a batch | Start a rename of 1,000 items. Stop the CTRM process (Activity Monitor, Task Manager or `kill -9`) during the batch. Start CTRM again. Select Roll Back. | The recovery dialog shows the batch. Roll Back restores all names. | |
| AC1.1 | Drag 1,000 files | Drag 1,000 files from Finder, Explorer or Files into the window. | All 1,000 items show in less than 2 s. | |
